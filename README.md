# Simple Uptime Monitoring Simulation

This Python script simulates a basic uptime monitoring system for critical logistics services. It periodically checks the simulated status of each service and reports whether it's UP or DOWN, highlighting potential issues.

## Language

`python`

## How to Run

Run the script using: python monitor.py. Press Ctrl+C to stop.
